# 查询模组

本目录存放独立查询模组，已接入 Windows 桌宠的 Codex / OpenAI 聊天入口。重启桌宠后生效，无需新增 Key。

| 模组 | 输入示例 | 数据来源 |
| --- | --- | --- |
| 天气 | 上海天气、北京明天天气、深圳后天天气、杭州未来7天天气 | Open-Meteo |
| 动漫更新 | 动漫更新、今天动漫更新、动漫更新 转生成为魔剑 | https://www.agedm.io/update |

天气必须提供城市；常用国内城市内置坐标，其余地点使用 Open-Meteo 地名查询，同名地点会请求补充信息。天气日期以查询地点时区为准，结果标注数据时间和来源。Open-Meteo 免费接口适合非商业使用，参见 https://open-meteo.com/en/docs 。

支持当前角色名称开头的提问，例如“爱丽丝今天有什么动漫更新呢”“爱丽丝，帮我查一下上海天气”。更新代码后需要重启桌宠以加载新模组。

查询列表中的 AGE 地址可点击打开。查询后也可发送“打开第1部动漫”“打开FX战士网页”或“FX戦士くるみちゃんが見たい、ウェブサイトをあけて”，程序在默认浏览器打开实际查到的详情页，收到系统打开成功回执后才确认成功。同名或不明确的请求会要求指定名称或序号，不随机打开页面。

也支持自然观看请求：“宝宝我想看fx展示久留美”“我要看FX战士久留美”“FX戦士くるみちゃんが見たい”。中文片名可匹配唯一的同音结果；省略季数时存在多季则要求指定。否定句不打开网页。

“宝宝我想看转生成魔剑的最新话”无需先查列表：程序提取片名，查询一周更新页面，并允许唯一的一字遗漏/误写匹配。当前展示列表中没有的片名也会到完整更新页面查找。匹配失败或多季不明确时会明确告知尚未打开；打开的是对应作品详情页，播放仍由用户在网站操作。

动漫在 AGE 一周更新页面内筛选，返回日期分组、名称、集数和详情地址；最多展示20条。无匹配仅表示该页面中没有记录。页面限制访问或结构变化时会明确报告失败。

入口 `index.mjs` 导出 `handleMods(text, { signal, fetcher })`：非查询返回 `null`，查询返回可直接展示的文字。请求支持取消、15秒超时及2MB响应上限。模组不执行网页脚本、不读取凭据、不把网页内容交给模型执行。

验证：在代码目录运行 `node --test tests/windows/mods.test.mjs`。
